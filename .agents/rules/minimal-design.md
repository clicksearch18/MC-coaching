# Streamlined Minimum Viable Design Rule

1. **One Goal Per Panel**: Every panel and modal must focus on a single user outcome with the minimum controls required.
2. **Zero Technical Jargon**: Never expose API keys, webhook URLs, `acc_...` IDs, HTTP routes, or backend provider names (`Outstand.so`) in the UI.
3. **Guided 3-Step Setup**: For Lead Magnets & DM CRM, guide the user through:
   - Step 1: Connect Instagram & Facebook (confirming connection status)
   - Step 2: Add Lead Magnet URL & Comment Keyword Trigger
   - Step 3: Test Keyword Trigger
   - Then transition into the clean Conversations Inbox.
4. **Visual Restraint**: Max 3–4 inputs per form, no nested card borders, no multi-line instruction paragraphs, and no rainbow badges.
